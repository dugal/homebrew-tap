# dugal/homebrew-tap

A Homebrew tap for tools published under the `dugal` GitHub account.

## Install

```
brew tap dugal/tap https://github.com/dugal/homebrew-tap
brew install dugal/tap/<formula>
```

## Formulas

Formulas live under `Formula/` and are pushed here by each project's
`publish-formula` step at release time. This README enumerates them
informally; the directory is the source of truth.
